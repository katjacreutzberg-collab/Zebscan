Configurable performance

Hybrid

A vacuum pane plus a thermally-broken secondary pane — you set the total thickness.

Hybrid pairs a Zebscan vacuum unit with an additional pane and a thermally-broken spacer bar, rather than a second gas-filled cavity. The effect is roughly double the insulation of a conventional triple-glazed unit, in a build-up that stays significantly thinner and lighter — the exact thickness is set project by project, to whatever depth the existing or new frame can actually take.

It is the specification for projects where neither a single vacuum pane nor a full triple unit is quite the right answer — where the frame has some depth to work with, and the brief calls for pushing performance as far as that depth allows.
